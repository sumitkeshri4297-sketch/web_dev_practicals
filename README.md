# Programming for Web Development — Practicals P1–P13

This pack contains beginner-friendly solutions based on the practical titles visible in the supplied screenshot.
Each HTML practical is a separate folder so you can open its `index.html` directly in a browser.

## Requirements
- VS Code (recommended)
- A web browser
- Git installed for P1–P4
- A GitHub account for P2–P4

## Run the HTML/CSS practicals
Open the relevant folder in VS Code and open `index.html` in a browser. You can also use the VS Code Live Server extension.
